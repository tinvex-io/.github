# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in any Tinvex project, please do not open a public issue. Email us at contacto@tinvex.io with a description of the problem, the steps to reproduce it and, if possible, its potential impact.

We will acknowledge your report as soon as we can, keep you informed while we investigate, and credit you once the issue is fixed if you wish.

## Scope

This policy covers the code and services published by Tinvex Exchange Limited. Please do not access data that is not yours, and do not disrupt the service while testing.

## Supported versions

Only the latest released version of each project receives security fixes.
